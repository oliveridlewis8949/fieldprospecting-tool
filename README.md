## Overview

Fieldprospecting provides a dedicated web workspace for people carrying out field prospecting activities. Because it runs in a browser, it can be used without installing a conventional desktop application.

The project is intended for individuals and teams who want a simple, focused prospecting utility. Aszafran is associated with the tool, which is provided as an HTML-based web project.
